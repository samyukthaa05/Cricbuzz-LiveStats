# 5–10 minute demonstration guide

1. Open **Home** and show the architecture, database status, and explicit SAMPLE / SEED DATA boundary.
2. Open **Live Match** and show the configured/credential-free API status, refresh control, and graceful unavailable state.
3. If credentials are configured, select a live match and expand its scorecard payload.
4. Open **Top Player Stats**, switch Test/ODI/T20I, and show leaderboard tables and Plotly charts.
5. Open **SQL Queries & Analytics**, execute one Beginner query such as Q3, then one Intermediate query such as Q14, then Advanced Q21 or Q23.
6. Open **CRUD Operations → Create player**, create a record, and show it in Browse & search.
7. Select it in **Update player**, change role/style, save, and show the updated record.
8. Demonstrate delete confirmation and the protected-history behavior on a seeded player.
9. Show `database/schema.sql`, `docs/database_schema.md`, and the requirement audit.
10. Close with security rules, API configuration, tests, and future PostgreSQL/provider-sync scope.
